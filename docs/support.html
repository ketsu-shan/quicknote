QuickNote 技术支持

快速记录任务，按重要程度分类，把注意力留给当下。QuickNote 支持 macOS 12.0 及更高版本。

提交问题 查看隐私政策

为什么看不到未来任务？

桌面便签聚焦今天和已经逾期的未完成事项。未来任务可在日历或“近期”页面查看。

日历为什么没有同步？

请在“系统设置 → 隐私与安全性 → 日历”中确认 QuickNote 已获授权，然后重新修改任务日期触发同步。

误删的任务能恢复吗？

可以。任务删除后会进入回收站，最多保留 30 天；超过期限或手动清空后无法恢复。

任务数据保存在哪里？

任务数据保存在你的 Mac 本地应用数据目录中。QuickNote 当前不提供账户或云端同步服务。

反馈时请提供

  • macOS 版本与 QuickNote 版本
  • 出现问题前的操作步骤
  • 不包含私人任务内容的截图（如适用）

GitHub Issue 是公开页面，请不要提交私人任务、日历内容、邮箱、证书或其他敏感信息。
